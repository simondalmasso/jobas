# OSS Hardening Notes

Current hardening principles:

- Argentina/LatAm focus is a product scope, not owner-specific coupling.
- Server ranking is generic public quality; candidate fit is computed from browser-local profile state.
- Named/manual opportunities live in `data/` with provenance and freshness metadata.
- OpenRouter credentials and CV content bypass the JOBAS Worker.
- MCP is a first-class public read-only interface.
- The retro desktop remains the product identity; OSS work should not redesign it.
- Automated browser CI mocks only JOBAS feed/provider boundaries and never consumes paid AI.

When updating this file, record only unresolved OSS/product blockers. Do not turn it into an application dossier.
